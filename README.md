# Git Stats

A Bash script that shows commit statistics for any Git repository: total commits, first and latest commit dates, top authors, and a bar chart of recent daily activity.

## Usage

'''bash
bash gitstats.sh                    # current repo, last 14 days
bash gitstats.sh path/to/repo       # another repo
bash gitstats.sh path/to/repo 30    # last 30 days
'''

## Requirements

Bash and Git (Git Bash on Windows) 
Powershell
